# Volta: диплинки и интеграция для VPN-сервисов

## 1. Добавление подписки

| Ссылка | Что делает |
|---|---|
| `volta://import/https://sub.example/abc` | Обычная подписка, ссылку видно и можно изменить |
| `volta://import/https://sub.example/abc?visible_subs=false` | Подписка со **скрытой** ссылкой |
| `volta://import/https://sub.example/abc?visible_subs=true` | Ссылка видна (так же, как без параметра) |
| `volta://import/https://sub.example/abc#Мой%20VPN` | Название подписки — после `#` |
| `volta://import?url=<url-encoded>&name=...&visible_subs=false` | То же в «query»-форме |
| `volta://crypt/<payload>` | **Зашифрованная** подписка, ссылка всегда скрыта |

`add/`, `sub/`, `subscribe/` работают так же, как `import/`.

В path-форме всё после `import/` — это адрес подписки вместе с его собственными
параметрами. Volta забирает из него только свои ключи (`visible_subs`, `server-type`),
остальное (`?token=…`) уходит провайдеру как было. Свои ключи можно ставить и после
`&`, даже если у адреса нет своего `?`:
`volta://import/https://sub.example/abc&server-type=lte:1,2`.

Повторное открытие ссылки с тем же адресом не дублирует подписку, а обновляет её.

### Скрытая ссылка (`visible_subs=false`)

- в приложении нигде не показывается адрес: ни в карточке, ни в редакторе, ни в ошибках;
- адрес нельзя изменить или скопировать — только название;
- подписка обновляется как обычно (вручную, при запуске, в фоне).

Без шифрования адрес всё ещё виден в самой диплинк-ссылке. Если это важно — используйте `crypt`.

### Зашифрованная ссылка (`volta://crypt/…`)

Адрес шифруется открытым ключом Volta (ECIES: P-256 + HKDF-SHA256 + AES-256-GCM),
расшифровать может только приложение. Инструмент для провайдера — `tools/volta_crypt.py`:

```bash
pip install cryptography
python3 tools/volta_crypt.py "https://sub.example/abc"
python3 tools/volta_crypt.py "https://sub.example/abc" --server-type "lte:1,2;home:3" --name "Мой VPN"
```

Внутрь можно положить просто адрес, JSON `{"url","name","server-type","visible_subs"}`
или целую ссылку `volta://import/...`. Ссылка остаётся скрытой, если **внутри**
не сказано `visible_subs=true`; `visible_subs` снаружи игнорируется — иначе любой
мог бы его дописать. `name` и `server-type` снаружи разрешены как подсказки.

Честное ограничение (как и у Happ): закрытый ключ лежит в приложении. Шифрование
защищает ссылку от чтения, пересылки и вставки в другой клиент, но не от разбора APK.

## 2. Включение и выключение

| Ссылка | Что делает |
|---|---|
| `volta://connect` | Включить в текущем режиме |
| `volta://connect?mode=home` | Включить в режиме Авто Home |
| `volta://connect?mode=lte` | Авто LTE |
| `volta://connect?mode=auto` | Авто Home+LTE (`home_lte`, `home+lte` тоже) |
| `volta://connect?mode=manual` | Свой выбранный сервер |
| `volta://disconnect` | Выключить (`off`, `stop`) |
| `volta://toggle` | Переключить |

Если разрешение на VPN ещё не выдано, Android сначала покажет системный запрос.

## 3. Разметка серверов: Home / LTE / балансеры

Подойдёт любой из трёх способов, их можно смешивать. Если нет ни одного,
работает старый способ — по словам в названии («LTE», «обход», «Авто»…).

### Способ 1 — JSON по группам

Тело подписки — JSON-объект со списками под ключами групп:

```json
{
  "title": "Мой VPN",
  "wifi":      ["vless://…#Германия", { "remarks": "Нидерланды", "outbounds": [ … ] }],
  "lte":       [{ "link": "vless://…", "name": "Москва LTE" }],
  "balancers": [{ "tag": "auto", "protocol": "vless", "settings": { … } }],
  "routing":   "happ://routing/…"
}
```

- Home: `wifi`, `home`, `h`; LTE: `lte`, `mobile`, `l`; балансеры: `balancers`, `auto`, `autobalancers`, `a`.
- Списки могут лежать и внутри `"groups": {…}` или `"servers": {…}`.
- Элемент списка: share-ссылка (или несколько в строке), полный Xray-конфиг, один outbound
  или объект `{"link": "...", "name": "..."}`.
- Можно отдавать в base64, заголовки `profile-title`, `subscription-userinfo` и т.п. работают как обычно.

### Способ 2 — префикс в названии

`[L] Москва`, `[H] Германия`, `[A] Автовыбор` (также `[LTE]`, `[HOME]`, `[WIFI]`, `[AUTO]`).
Префикс должен стоять в самом начале; в приложении он не показывается.

### Способ 3 — в диплинке

`&server-type=lte:1,2,5-7;home:3;auto:9` — номера серверов по порядку в подписке, с 1.
Группы разделяются `;` или `|`, номера — `,`; диапазоны `5-7` разрешены.
Разметка сохраняется с подпиской и применяется при каждом обновлении.

### Приоритеты

JSON-группа → префикс → `server-type` → название. Ручной выбор группы пользователем
главнее всего. Группа, размеченная провайдером явно, считается полной: сервер без
разметки не попадёт в неё по случайному слову «LTE» в названии.

## 4. Если LTE-серверов нет

Режимы «Авто LTE» и «Авто Home+LTE» сворачиваются в «Авто Home»: на главном экране
вместо трёх групп — Home и приглушённая плашка «LTE · нет серверов», плитка LTE в
шторке становится неактивной, сайты для выбора группы не проверяются. Когда LTE-серверы
появятся, всё вернётся само — выбранный режим не теряется.
