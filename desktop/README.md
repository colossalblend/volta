# Volta для Windows

Тот же Volta, что и на Android: медный диск на главном экране, подписки, серверы по группам
Home и LTE, автовыбор самого быстрого сервера. Внутри то же ядро Xray той же версии, что и в
приложении для телефона.

## Как установить

1. Откройте страницу релизов проекта на GitHub и скачайте файл
   **`volta-…-windows-x64-setup.exe`** (для Windows 10 1809 и новее и Windows 11, 64 бит).
2. Запустите его. Права администратора не нужны: Volta ставится только для вашей учётной записи,
   по умолчанию в `%LOCALAPPDATA%\Programs\Volta`. Папку, ярлыки на рабочем столе и в меню «Пуск»
   и автозапуск можно выбрать на втором шаге.
3. Нажмите «Запустить Volta», затем **Добавить**, вставьте ссылку на подписку от VPN-сервиса и
   нажмите на медный диск. В приложении нет своих серверов — нужна ссылка от VPN-сервиса.

Без установки: скачайте **`volta-…-windows-x64-portable.zip`**, распакуйте в любую папку и
запустите `Volta\Volta.exe`.

Если Windows покажет окно «Windows защитила ваш компьютер», нажмите «Подробнее» →
«Выполнить в любом случае»: у сборки пока нет платной подписи разработчика.

### Обновление и удаление

- Новая версия ставится поверх старой: установщик сам находит прежнюю установку (и установку
  старым MSI-установщиком прежних сборок), просит Volta закрыться (VPN отключается, прокси Windows
  возвращается), заменяет только файлы программы и запускает Volta снова. Папку с подписками и
  настройками `%APPDATA%\Volta` установщик **никогда** не трогает.
- Обновление из приложения (Настройки → О приложении) делает то же самое без вопросов.
- Удалить: «Параметры → Приложения → Volta → Удалить» или `Uninstall Volta.exe` в папке программы.
  Удаление закрывает Volta, возвращает прокси Windows, убирает ярлыки, автозапуск и ссылки
  `volta://`. Вопрос «Удалить также подписки и настройки?» по умолчанию выключен — данные
  остаются, и после новой установки всё будет на месте.
- Ключи для администраторов: `setup.exe --silent [--dir <папка>] [--no-desktop-shortcut]
  [--no-start-menu] [--autostart] [--launch]` (или `/S`), удаление без окна —
  `"Uninstall Volta.exe" --uninstall --silent [--remove-data]`. Журнал установщика:
  `%TEMP%\Volta-setup.log`.

### Если Volta не запускается

- Любая ошибка при запуске показывает окно с путём к журналу и кнопкой «Открыть папку журнала».
  Журналы лежат в `%APPDATA%\Volta\logs`: `crash-<время>.log` (ошибка, версия Windows и Java,
  видеокарта и драйвер, режим графики) и `volta.log` (как прошёл запуск). Пришлите их разработчику.
- Если окно не открывается, мерцает или остаётся чёрным (старые драйверы видеокарты, удалённый
  рабочий стол, виртуальные машины), включите Настройки → «Безопасный режим графики»: окно будет
  рисоваться без видеокарты. Если запуск оборвался раньше, чем появилось окно, Volta включит этот
  режим сама при следующем запуске.
- Если Volta уже запущена, но зависла, повторный запуск предложит «Закрыть старую и открыть»:
  зависшая копия закрывается, настройки прокси Windows возвращаются.

## Как это работает

- Volta запускает ядро Xray (`xray.exe`, лежит рядом с приложением) и включает
  **системный прокси Windows** на `127.0.0.1`: через VPN пойдут браузеры и все программы,
  которые берут прокси из настроек Windows.
- Для программ, которые прокси Windows не читают (например, Telegram), укажите им прокси
  вручную: адреса показаны на главном экране, обычно HTTP `127.0.0.1:10809` и
  SOCKS5 `127.0.0.1:10808`. Если эти порты заняты другой программой, Volta возьмёт свободные.
- Прежние настройки прокси Volta сохраняет и **всегда возвращает**: при отключении, при
  выходе и даже после сбоя — при следующем запуске.
- Крестик окна прячет Volta в трей (значок у часов), VPN продолжает работать. Подключить,
  отключить и выйти можно из меню значка.
- Ссылки `volta://` из браузера открываются в Volta.

## Что умеет так же, как на Android

- **Маршруты**: свои наборы правил (сайт, адрес, geosite, geoip → через VPN, напрямую или
  блок), готовые списки, порядок правил, импорт и экспорт JSON, правила из подписок (заголовки
  провайдера и формат Happ), выбор набора для каждой подписки. Конфиг ядра собирается тем же
  кодом, что и на телефоне.
- **Блокировка рекламы** (Реклама и трекеры, Строгая, Семейная), свой список трекеров Volta и
  список того, что никогда не блокируется, **блокировка торрентов**. Через системный прокси
  браузер называет ядру сайт по имени, и правила срабатывают на это имя.
- **AmneziaWG, Hysteria первой версии и OpenFlux**: те же помощники, что и на Android
  (`voltaproxy.exe`, `openflux.exe` лежат рядом с `xray.exe`). Если OpenFlux просит пройти
  проверку, страница открывается в браузере, на главном экране есть кнопки «Открыть страницу»
  и «Готово».
- **Перенос**: Настройки → «Сохранить в файл» / «Восстановить из файла». Формат тот же, что на
  Android: файл с телефона открывается на компьютере и наоборот.
- **Обновления**: Настройки → О приложении. «Проверка обновлений» ищет новую версию при запуске
  и раз в несколько часов, «Бета-версии» берут и тестовую сборку ветки main. Установщик
  скачивается, проверяется по SHA-256 и запускается, Volta закрывается, чтобы он её обновил.
- **Трафик** за сегодня, этот и прошлый месяц и по дням за две недели: нажмите на полоску дня
  или проведите по ним мышью — покажутся дата, сколько получено и отправлено; стрелки ← →
  листают дни. **Проверка сети** («Нет интернета» вместо бесконечного подключения), темы,
  включая **Material** (цвет берётся из акцентного цвета Windows), и **15 языков** — те же
  переводы, что в приложении для телефона.
- **Переключение серверов без отключения**: VPN остаётся включённым, на главном экране
  «Переключение». Если выбранный вручную сервер не ответил, Volta возвращается на прежний и
  говорит об этом. Несколько нажатий подряд переключают один раз — на последний сервер. При
  подключении в авторежиме соревнуются несколько лучших недавних серверов, а полное сравнение
  идёт уже после подключения.
- **«Проверить все»**: результаты появляются по строкам, вверху «Проверено N из M» и кнопка
  «Остановить»; список пересортировывается один раз, в конце. Старые замеры бледнее.
  Фильтры, сортировка, группировка, поиск и раскрытые страны сохраняются.
- **«Авто по подписке»**: под выбором режима — «Выбирать из: Все подписки · …» (при двух и более
  подписках); выключается в Настройках («Авто по подпискам»).
- **Проверка Gemini**: в меню сервера (правая кнопка) — «Проверить Gemini»; для подключённого
  сервера запрос идёт через сам туннель, для остальных — через временный `xray.exe`. Настройка
  «Проверять Gemini после подключения» показывает ответ на главном экране.
- **«Lite-оформление»** в Настройках выключает все анимации окна сразу.

## Чего в Windows нет и почему

- **Выбор приложений** (раздельное туннелирование): Volta работает через системный прокси, а он
  один на все программы, поэтому разделить трафик по приложениям нельзя. Вместо этого на экране
  «Маршруты» есть «Сайты мимо VPN»: их браузер и программы открывают напрямую.
- **Режим TUN** (весь трафик компьютера, включая программы без прокси): ядро его умеет, но
  ему нужны права администратора и своя настройка маршрутов, и надёжно проверить это в сборке
  нельзя. Поэтому его нет; на экране он не показывается.
- **Безопасный поиск** в семейном режиме: он работает через DNS, а браузер за прокси DNS у Volta
  не спрашивает. Сайты для взрослых при этом скрываются.
- **Раздача по Bluetooth**: на Android ещё в работе, в Windows-версию не переносилась.

## Где Volta хранит данные

`%APPDATA%\Volta`: подписки, настройки и трафик по дням (`volta.json` и его последняя исправная
копия `volta.json.bak`), журналы (`logs\`), списки geoip/geosite, скачанное обновление
(`update\`). Сама программа — в `%LOCALAPPDATA%\Programs\Volta` (или в выбранной папке), там
ничего пользовательского нет. Удалить Volta полностью — удалить программу, отметив «Удалить также
подписки и настройки».

## Сборка из исходников

Нужен JDK 21. Ядро в репозиторий не кладётся: положите `xray.exe`, `geoip.dat` и `geosite.dat`
(из релиза Xray-core `Xray-windows-64.zip` той версии, что в `xray.version`) в
`desktop/resources/windows-x64/`. Помощники собираются Go: `voltaproxy.exe` из
`helper/voltaproxy`, `openflux.exe` из OpenFlux на коммите `openflux/VERSION` вместе с
`openflux/voltaflux` (как в шаге «Helpers» в `windows.yml`). Тексты экранов берутся из
`app/src/main/res` при сборке. Затем из папки `desktop`:

```
gradlew.bat run              # запустить
gradlew.bat test             # тесты
gradlew.bat createDistributable   # папка с Volta.exe (build\compose\binaries\main\app)
```

Установщик — отдельная программа на C#/WPF в `desktop/installer` (.NET Framework 4.7.2, он есть в
Windows 10 с версии 1803, поэтому установщику ничего не нужно). Он же — деинсталлятор. Сборка
(нужен .NET SDK):

```
dotnet build installer\VoltaSetup.csproj -c Release                 # без приложения = Uninstall Volta.exe
dotnet build installer\VoltaSetup.csproj -c Release -p:VoltaPayload=payload.zip -p:VoltaPayloadInfo=payload.json -p:VoltaVersion=1.2.3
```

`payload.zip` — содержимое папки `build\compose\binaries\main\app\Volta` вместе с
`Uninstall Volta.exe`, `payload.json` — `{"version": "1.2.3", "versionCode": 123, "size": <байт>,
"files": <число>}`. Ключ `--screenshots <папка>` рисует все страницы установщика в PNG.

Проверка собранного приложения без окна:
`Volta.exe --self-test self-test.log --shots screens` — запускает ядро, поднимает тестовый
туннель через локальный сервер, проверяет порты, счётчики трафика и рисует все экраны в PNG.
С ключом `--proxy` ещё включает и возвращает системный прокси. Код выхода 0 — всё в порядке.

В GitHub Actions всё это делает `.github/workflows/windows.yml`: берёт ядро той же версии,
что и Android-сборка (из `app/libs/libv2ray.aar`), проверяет его контрольную сумму,
собирает помощники, прогоняет тесты, проверяет, что ядро принимает все виды конфигов Volta
(включая блокировку рекламы и маршруты), собирает приложение, установщик и portable-архив и
проверяет их от имени пользователя с кириллицей и пробелом в имени (`installer/ci/installer-test.ps1`):
переход со старой MSI-установки, тихая установка, самопроверка установленного приложения
(туннель, системный прокси, блокировка по имени сайта, помощники, обновление, перенос из файла
Android), окно и повторный запуск, зависшая копия, обновление поверх запущенной Volta, удаление с
данными и без. Страницы установщика и окна сохраняются картинками; файлы уходят в релиз вместе с
`windows-update.json`.
